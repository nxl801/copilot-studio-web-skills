## 独立模拟场景

评估者只收到 skill、用户请求和页面事实，没有收到预期答案。未提供真实浏览器或租户权限。完整轨迹见 [独立评估记录](evaluation-forward-test.md)。

| 场景 | 观察到的判断 |
|---|---|
| 只保存 flow 草稿，Test 灰色 | 不发布、不声称运行通过，标记挂接可能未完成 |
| 已导入 TEST，但连接未绑定且 agent 未发布 | 继续有权完成的配置与既定发布，不把导入成功当完整交付 |
| Run 超时，但运行成功且已有同关联订单 | 核对实例与业务结果，不重新触发 |
| GitHub harness 知识入口不同，出现 nxl801 | 保留现有框架，分别核查来源支持与实际计费，不能仅按名称下结论 |
| Canvas 只共享使用权限，SharePoint 权限缺失 | 仅授予 User，分别报告应用共享与数据访问 |

这是一轮定性模拟，没有测量触发准确率或真实网页成功率。

- 将异步回调验收明确放在目标 Teams 会话。
